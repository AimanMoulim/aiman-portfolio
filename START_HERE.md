## The Fastest Path to Launch

### 🏃 5-Minute Deploy

```bash
# 1. Download this project (already done!)

# 2. Create GitHub repo
# Go to: https://github.com/new
# Name: <your-username>.github.io
# Make it Public

# 3. Push your code
git init
git add .
git commit -m "Portfolio"
git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
git branch -M main
git push -u origin main

# 4. Enable GitHub Pages
# Go to: Settings → Pages → Select "GitHub Actions"

# 5. Done! ✨
# Your site: https://<your-username>.github.io
```

## Common Questions

**Q: How do I change my name?**
A: Edit `components/Header.tsx` and `components/Hero.tsx`. See [SETUP.md](./SETUP.md).

**Q: Can I add more apps?**
A: Yes! Edit the `apps` array in `components/Apps.tsx`. See [SETUP.md](./SETUP.md).

**Q: How do I change colors?**
A: Edit `app/globals.css`. See [SETUP.md](./SETUP.md).

**Q: Will it work on my phone?**
A: Yes! 100% responsive and mobile-friendly.

**Q: Is it fast?**
A: Super fast! Static site, loads in <1 second.

**Q: Do I need to pay?**
A: No! GitHub Pages is free. Everything is open source.
